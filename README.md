# Persona 5 Royal Countdown
Rainmeter skin for the countdown function of the video game Persona 5 Royal.

## Before you install the skin

Install the fonts in the Fonts folder first.

## Variables

Edit the following in the [Variables] section:

- "Date": The deadline in format: %m/%d/%Y (%H:%M:%S)
- "Event": Event name on the deadline day
- "MainTask": Your major task before the event occurs
- "Step": The necessary step to do the major task or the side objective

Example:
```
[Variables]
Date=8/15/2026 (00:00:00)
Event=Fifth event
MainTask=Prepare for the fifth event
Step=Build the CMS for the showroom website
```
